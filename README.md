## Proyectos destacados

### BOXMANAGER

**Sistema de gestión para talleres automotrices**

Aplicación web progresiva orientada a digitalizar la gestión operativa de un taller automotriz.

**Tecnologías:** React · Vite · Supabase · PostgreSQL · Vercel

Principales áreas:

* Gestión de clientes
* Gestión de vehículos
* Órdenes de ingreso
* Registro fotográfico
* Información del servicio
* Diseño adaptable para celulares, tabletas y computadoras
* Optimización del almacenamiento
* Gestión de procesos operativos

El sistema está diseñado a partir de procesos reales de operación de un taller automotriz.

---

### CACESSIM

**Plataforma de preparación para evaluaciones CACES**

Plataforma web orientada a la preparación de evaluaciones relacionadas con Enfermería y CACES.

**Tecnologías:** Next.js · Supabase · PostgreSQL · Vercel

Características principales:

* Banco de más de 10.000 preguntas
* Modo de práctica
* Modo de examen
* Exámenes de 100 preguntas
* Temporizador
* Selección de preguntas
* Registro de resultados
* Persistencia de información

## Metodología de desarrollo

Creo que un buen producto de software comienza por **comprender correctamente el problema**.

```text
                    PROBLEMA REAL
                         │
                         ▼
                 ANÁLISIS DEL PROCESO
                         │
                         ▼
                 DISEÑO DE LA SOLUCIÓN
                         │
                         ▼
               ARQUITECTURA DE DATOS
                         │
                         ▼
                    BACKEND / API
                         │
                         ▼
                     INTERFAZ
                         │
                         ▼
                   AUTOMATIZACIÓN
                         │
                         ▼
                    DESPLIEGUE
                         │
                         ▼
               MEJORA CONTINUA
```

La tecnología es el medio. El objetivo final es construir una solución que **aporte valor al usuario y al negocio**.
